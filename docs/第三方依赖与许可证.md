# 第三方依赖与许可证清单

以下组件通过 npm 安装，具体锁定版本以根目录 `package-lock.json` 为准。本项目自行实现会议室推荐、冲突校验、预约状态机、审批复核和业务页面，未将第三方组件声明为原创代码。

| 组件 | 用途 | 许可证类型 |
|---|---|---|
| Vue | 前端视图框架 | MIT |
| Vite | 前端构建工具 | MIT |
| Vue Router | 页面路由 | MIT |
| Pinia | 登录状态管理 | MIT |
| Element Plus | UI 组件 | MIT |
| Axios | HTTP 客户端 | MIT |
| Day.js | 日期格式化 | MIT |
| Express | HTTP 服务框架 | MIT |
| Prisma / Prisma Client | ORM 与数据库工具 | Apache-2.0 |
| Zod | 输入数据校验 | MIT |
| bcryptjs | 密码哈希 | MIT |
| jsonwebtoken | JWT 实现 | MIT |
| Vitest | 自动化测试 | MIT |
| Supertest | API 测试 | MIT |

许可证信息应在依赖升级后重新核验，不应仅依赖本文档。
