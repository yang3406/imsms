# 智能会议预约管理系统 V1.0 需求规格说明

## 产品目标

为企业员工和会议室管理员提供本地化的会议资源预约工具，通过可解释的规则计算避免时间冲突和资源错配，并保留审批和状态流转记录。

## 角色

- 普通员工：查询资源、获取推荐、提交预约、查看本人预约、取消、签到、开始及结束会议。
- 系统管理员：具备员工权限，并可维护会议室和维护时段、审批预约、管理部门与用户、配置规则、查看统计和审计日志。

## 核心闭环

会议室维护 → 条件查询 → 规则推荐 → 预约提交 → 冲突校验 → 管理员审批 → 状态通知 → 签到与会议执行 → 日历和统计更新。

## 核心数据实体

部门、用户、会议室、维护时段、预约规则、预约、通知和审计日志。所有演示数据均为脱敏虚构数据。

## 功能验收基线

1. 有效账号可以登录，无效凭据被拒绝。
2. 推荐结果只包含容量、设备、时间和维护状态均符合要求的会议室。
3. 重叠预约被服务端拒绝，相邻预约允许提交。
4. 普通员工无法进入或调用管理员接口。
5. 预约批准前执行第二次冲突校验，驳回必须填写原因。
6. 已批准预约依次经过签到、进行中和已完成状态，非法状态操作被拒绝。
7. 预约、审批和会议执行操作均能在状态时间线和审计日志中查询。
8. 日历、工作台和统计结果来自数据库真实记录。
