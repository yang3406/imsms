## 问题与复测

1. 初测发现按记录总数生成预约编号可能与历史编号重复。已改为日期、毫秒片段和随机段组合，复测通过。
2. 初测发现完成会议后，接口响应早于最新审计日志写入，导致时间线需要刷新。已调整为写入日志后重新读取详情，复测通过。
3. 初次 SQLite 初始化受到执行环境文件写入限制影响。确认数据库路径后由 Prisma 成功创建并初始化，健康检查与测试通过。
4. 依赖初次安装存在安全审计告警。已更新或调整到审计无已知漏洞的版本，重新构建和测试通过。

- Element Plus 供应商包压缩前约 922 KB，生产构建给出大块提示；gzip 后约 297 KB，不影响本地核心功能。
- 邮件、短信、企业微信、门禁硬件、真实 AI 模型和多租户不属于 V1.0 范围。
- 当前使用本地演示密钥和脱敏账号；正式部署前必须修改 `JWT_SECRET` 和演示密码，并配置 HTTPS 与生产级备份策略。
