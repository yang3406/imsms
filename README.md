# 智能会议预约管理系统 V1.0

“智会预约”是一套可本地运行的企业会议资源预约管理系统。系统使用规则驱动的会议室推荐算法，完成会议室维护、可用性匹配、冲突检测、预约申请、管理员审批、签到、会议开始与结束、日历展示、通知和审计追踪。

## 技术架构

- 前端：Vue 3、Vite、TypeScript、Vue Router、Pinia、Element Plus
- 后端：Node.js、Express、TypeScript、Zod
- 数据：SQLite、Prisma ORM
- 安全：bcrypt 密码哈希、JWT 身份认证、角色权限校验
- 测试：Vitest、Supertest、Vue Test Utils

项目完全使用本地 SQLite，不需要云服务、付费接口或外部密钥。

## 环境要求

- Node.js 20 或更高版本
- npm 10 或更高版本

本项目已在 Node.js 24.13.0、npm 11.6.2、Windows 环境中验证。

## 安装与运行

```powershell
npm install
npm run db:init
npm run dev
```

- Web 管理端：http://localhost:5173
- API 健康检查：http://localhost:3000/api/health

生产构建和测试：

```powershell
npm run build
npm test
```

## 推荐体验流程

1. 使用 `employee` 登录，在“智能预约”中选择未来日期、人数和设备。
2. 查看会议室推荐分数及推荐原因，选择会议室并提交申请。
3. 使用 `admin` 登录，在“预约审批”中批准或驳回申请。
4. 返回员工账号，在“我的预约”中查看状态变化和操作时间线。
5. 在允许签到的时间内依次执行签到、开始会议和结束会议。
6. 在“预约日历”和管理员“统计分析”中查看数据变化。
7. 可将常用会议保存为模板、创建 2 至 8 周的周期预约，并在“我的预约”导出 CSV。

## 业务规则

- 待审批、已批准、已签到和进行中的预约会占用会议室时段。
- 两个预约满足“开始时间早于另一预约结束时间，且结束时间晚于另一预约开始时间”时判定为重叠。
- 会议室停用、容量不足、设备不匹配、维护时段或开放时间之外均不可预约。
- 管理员审批时再次校验冲突，避免申请后资源状态变化导致重复占用。
- 预约状态只能按规定顺序流转，所有核心操作写入审计日志。
